# Profile asset credits

`profile-hero.svg` is an original vector banner for this profile.

`trophies.svg` is generated by [GitHub Profile Trophy](https://github.com/ryo-ma/github-profile-trophy), served by the community endpoint `https://trophy.ryglcloud.net/` listed in its upstream README.
